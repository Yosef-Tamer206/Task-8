# ContactHub - Smart Contact Manager

A browser-based contact manager: add contacts with photos, mark favorites and emergency contacts, and find anyone fast with live search.

**Live demo:** https://yosef-tamer206.github.io/Task-8/

## Features

- Add, edit and delete contacts, with a delete-all option
- Contact photo upload with initials fallback
- Favorites list and emergency contacts list
- Live search with match highlighting
- Input validation with helpful messages
- Confirmation dialogs for destructive actions (SweetAlert2)
- Contacts persist in `localStorage`

## Tech Stack

- HTML5, CSS3, vanilla JavaScript
- Bootstrap 5
- SweetAlert2
- Font Awesome icons

## Run Locally

```bash
git clone https://github.com/Yosef-Tamer206/Task-8.git
cd Task-8
```

Open `index.html` in a browser.

## Notes

- All data stays in the browser's `localStorage`; there is no backend or sync.
